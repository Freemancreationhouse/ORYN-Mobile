ORYN Mobile v2.0 Standalone Interface Audit
===========================================

Baseline: user-provided ORYN-Mobile Android Studio project.
Frontend: bundled from the user's current working ORYN desktop package (static/dist + ORYN custom assets).

Architecture changes:
1. ORYN frontend is packaged inside the APK under app/src/main/assets/www.
2. App starts a loopback-only local server at 127.0.0.1:8765 and opens the bundled ORYN UI immediately.
3. No Raspberry Pi/table discovery is required for application launch.
4. Background discovery never hides or blocks the ORYN interface.
5. Connect Table allows manual address or local Wi-Fi discovery.
6. When a remote ORYN table is selected, the existing frontend table/base-URL mechanism points API/WebSocket traffic to that table.
7. Local shell rejects machine-motion actions when no table is connected; it never performs machine motion itself.
8. Pattern Forge Android file chooser support remains enabled.

Important boundary:
The APK is standalone for its interface and lifecycle. Actual machine motion still requires a reachable ORYN machine backend/controller. No Theta–Rho/motion mathematics were reimplemented in Android Java in this release.
