ORYN Mobile v3.0.0 - true standalone startup correction

Cause of v2 startup gate:
- The APK-local server answered HTTP on 127.0.0.1:8765.
- The locked ORYN frontend considers its backend connected only after /ws/status opens.
- v2 did not implement WebSocket upgrade/status, so the UI stayed behind "Connecting to Backend".

v3 correction:
- Implements APK-local /ws/status with the same status_update envelope used by ORYN.
- Local status reports connection_status=false: ORYN app is ready, physical table is disconnected.
- Implements benign /ws/cache-progress and /ws/logs endpoints.
- On every fresh app launch, ORYN starts against the APK-local runtime before any table discovery.
- Table discovery remains background-only and cannot block the ORYN UI.
- Tapping Connect Table switches the unchanged frontend to the selected real ORYN backend.

No Pi source, Windows source, Theta-Rho motion mathematics, homing, calibration, Pattern Forge,
or locked ORYN frontend code was modified.
