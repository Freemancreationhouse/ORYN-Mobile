ORYN Android V10.4.1 — Pi TMC2208 + Phone Hotspot
===================================================

Use this folder as the ROOT of your Android GitHub repository.
Do not put this folder one level inside another repository folder.

GitHub Desktop:
1. Make a backup/branch of your current working Android repository.
2. Replace the repository contents with the CONTENTS of this package.
3. In GitHub Desktop, review the changes.
4. Commit: ORYN Android - Pi TMC2208 phone hotspot sync
5. Click Push origin.
6. On github.com open the Android repository -> Actions -> Build ORYN Android APK.
7. Open the newest successful run.
8. Download artifact: ORYN-V10.4.1-PI-TMC2208-HOTSPOT-APK
9. Inside it: ORYN-V10.4.1-PI-TMC2208-HOTSPOT-debug.apk

Phone-hotspot connection:
1. Turn on the Android phone hotspot (2.4 GHz is the safest Pi-compatible choice).
2. Make sure the Raspberry Pi has that hotspot SSID/password saved and joins it.
3. Open ORYN Android.
4. Tap Scan for ORYN.
5. The app first tries oryn.local:8080 / oryn.local, then scans private /24 interfaces including the phone tether/hotspot interface.
6. If Android blocks discovery on a particular phone, open the phone Hotspot > Connected devices page, note the Pi IP, then use Add ORYN Pi Manually with:
   http://PI-IP:8080

Important:
- The Android app does NOT change GRBL $100/$101 just by connecting.
- The working Pi backend remains the motor/motion authority.
- For this current hardware: Uno + CNC Shield + TMC2208 + no MS jumpers = TMC2208 external 1/8.
- Existing Direct ESP32 support remains present but is separate from Pi mode.
