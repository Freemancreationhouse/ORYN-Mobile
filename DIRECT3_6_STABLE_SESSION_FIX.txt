ORYN Direct ESP32 V10.4.1 — Direct3.6 Stable Session Fix

Purpose
- Stop the repeating WebView reload / unstyled UI flash seen every few seconds.
- Prevent background FluidNC probes from opening a second Telnet connection while Home or pattern playback owns the controller.
- Keep Direct ESP32 identity stable in the header while Direct mode is active.

Changes
1. Automatic ORYN/Pi HTTP discovery no longer runs after startup when Direct ESP32 is already configured.
2. Native discovery never calls location.reload().
3. directProbe() returns the existing motion-session health while Home/pattern playback is active instead of opening another Telnet socket.
4. Direct transport rehydration skips $I probing while Home/pattern playback is active.
5. Direct /api/settings reports the Direct ESP32 app name so the single-table header remains stable.

Preserved
- 100-pattern offline library
- Pattern Designer
- Pattern Forge
- Theta–Rho conversion math
- Saved Theta/Rho calibration
- Smart Wi-Fi / Home Wi-Fi connection
- Direct Home/pattern command path

No ESP32 reflash is required.
